# Bilateral language projection (operational)

## Thesis

Language is a **projection** of higher structure — **from both sides**:

| Side | Speaks | Not |
|------|--------|-----|
| Human | intent, constraints, claims | the full manifold |
| Domain | code names, rplc law, E_ref notes, field packs, LM scout text | the full manifold |

OPEN is a **section** that glues projections under restriction into a shared interface.
Disagreement is **residue** (STOP / ROTATE), never forced OPEN.

## Domains as projection sources

| Domain | Extractor | Typical interface words |
|--------|-----------|-------------------------|
| `code` | files, defs, headings | code, test, api, file |
| `rplc` | CLAIMS, rplc_sheaf | open, stop, residue, measure, audit |
| `eref` | topology notes + derive | strain, prior, geometry, park, sequence |
| `field` | harness / multiplane docs | plane, pack, ingest, scout, certify |
| `lm` | scout text | local, model, measure |

## MCP API

```
project_human(text?)
project_domain(domain, text?)
project_align(domain?)     # empty ⇒ multi-domain bilateral
measure(mode="project")    # same as multi-domain align
```

## Regimes

| Regime | Meaning | CODE? | OPEN? |
|--------|---------|-------|-------|
| `glue_ok` | shared interface holds | yes | candidate if other gates pass |
| `partial_section` | some glue | careful | usually no |
| `frustrated` | no interface glue | no | **blocked** if all domains |

## What this is not

- Not a proof of sheaf cohomology
- Not permission to skip smoke/rplc measures
- Not “the model understood you”
